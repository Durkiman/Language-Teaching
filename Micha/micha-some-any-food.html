Countable or Uncountable?

Some foods you can count one by one — an apple, two apples, three apples. Other foods you can't count that way — you can't say "one rice" or "two waters". English treats these two types of nouns differently.

Certains aliments se comptent un par un — une pomme, deux pommes, trois pommes. D'autres ne se comptent pas de cette façon — tu ne peux pas dire "un riz" ou "deux eaux". L'anglais traite ces deux types de noms différemment.

Two Types of Food Nouns

Deux types de noms

Countable — tu peux compter
  • an apple / two apples
  • an egg / three eggs
  • a banana / four bananas
  • a tomato / five tomatoes
Uncountable — tu ne peux pas compter
  • rice
  • water
  • bread
  • cheese

Uncountable nouns don't have a plural form — you never say "rices" or "breads".

Les noms indénombrables n'ont pas de forme plurielle — on ne dit jamais "rices" ou "breads".

Some / Any

"Some" et "any" — du / de la / des

SOME → positive sentences  |  ANY → negative & questions
TypeRuleExample
Positive ✅someThere is some milk in the fridge.
Negative ❌anyThere isn't any bread.
Question ❓anyIs there any cheese?

"some" pour le positif · "any" pour le négatif et les questions

With Countable AND Uncountable

Countable: There are some apples. / There aren't any apples. / Are there any apples?
Uncountable: There is some rice. / There isn't any rice. / Is there any rice?
💡 Tip: "some" and "any" work the same way for both types — the only thing that changes is "is" vs "are" (singular vs plural)!

"some" et "any" fonctionnent pareil pour les deux types — seul "is"/"are" change.

Special Case: Offers & Requests

Sometimes we use "some" in a question — when we offer something or ask for something politely.
"Would you like some water?" / "Can I have some bread, please?"

Parfois on utilise "some" dans une question — quand on offre quelque chose ou qu'on demande poliment.

⚠️ Common mistakes:

❌ "There is some rices." → ✅ "There is some rice." (uncountable = no plural!)

❌ "There isn't some bread." → ✅ "There isn't any bread." (negative = any)

❌ "Are there some eggs?" → ✅ "Are there any eggs?" (question = any, usually)

Indénombrable = jamais de -s · Négatif → any · Question → any (sauf offres polies)
